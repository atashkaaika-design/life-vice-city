LIFE: VICE CITY — MVP prototype

Files:
- index.html: application
- manifest.webmanifest: install metadata
- sw.js: offline cache

To install on iPhone:
1. Host this folder on an HTTPS static host (for example GitHub Pages or Netlify).
2. Open the HTTPS address in Safari on iPhone.
3. Tap Share -> Add to Home Screen.
4. Launch VICE CITY from the new home-screen icon.

Data is currently stored locally in this browser on this device. Use Progress -> Export my save file regularly.
This MVP does not yet include real AI generation, cloud sync, push notifications, or a full 3D GTA-like world. The mission planner currently creates an editable starter outline. Those are later development steps.
